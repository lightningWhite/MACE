# Decision Records

One file per fork in the road: what was decided, what was rejected, and why.

The point is that a decision made once shouldn't be re-argued from scratch six
months later — and that if it *is* revisited, the reasons are on the table.

| # | Decision | Status |
|---|---|---|
| [0001](0001-yaml-as-authoring-format.md) | YAML for authoring, compiled JSON at runtime | Accepted |
| [0002](0002-unified-entity-model.md) | One Entity type replaces player / interactiveElement | Accepted |
| [0003](0003-structured-conditions-and-effects.md) | Structured conditions and effects, not magic strings | Accepted |
| [0004](0004-deterministic-seeded-simulation.md) | Deterministic simulation with named RNG streams | Accepted |
| [0005](0005-python-core-with-pyodide.md) | Python engine core, browser via Pyodide | Accepted, revisitable |
| [0006](0006-tempo-combat.md) | Tempo combat over dice rolls | Accepted |
| [0007](0007-full-market-economy.md) | A simulated market economy, not fixed prices | Accepted |

**Format:** Context (what problem), Decision (what we're doing), Alternatives
(what we rejected and why), Consequences (what this costs us).
